# StudyPath AI 🎓

### AI-Powered Adaptive Learning Platform

StudyPath AI is an adaptive learning platform that personalizes a student's learning journey using **AI, performance analysis, confidence calibration, and adaptive planning**.

Instead of giving every student the same learning path, StudyPath identifies what a student needs to learn next based on their actual performance and confidence.

## 🚀 Key Features

- 🤖 AI-generated assessments
- 📊 Mastery and confidence tracking
- 🎯 Confidence–mastery calibration gap
- 🧠 Adaptive learning state classification
- ⚡ Next Best Action recommendation
- 📅 Personalized daily study plan
- 💬 AI Tutor for topic-specific learning
- 📝 Adaptive practice questions
- 📈 Learning progress tracking
